棋盘格打飞机

双人对战 - 同屏热座模式

游戏规则

1. 两名玩家各拥有一个 10×10 的棋盘，轮流在棋盘上布置 3 架飞机

2. 飞机形状（10格）如下，可旋转4个方向：

✈ ← 机头 ■ ■ ✈ ■ ■ ← 机翼 ■ ■ ■ ■ ← 机尾

3. 双方布阵完成后，交替向对方棋盘开炮

4. 命中机头 → 击落（飞机消失）｜命中机身 → 击伤｜未命中 → 击空

5. 首先击落对方全部 3 架飞机的玩家获胜！
